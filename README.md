# dev-lab 🧪

Este repositorio es mi **laboratorio personal de desarrollo**.

Aquí voy guardando **todo lo que programo para practicar y aprender**, desde ejercicios sencillos hasta prácticas más completas o “mini-proyectos”.  
No es un portfolio ni un proyecto final, sino un espacio donde registro mi crecimiento como desarrollador sin tener que crear decenas de repositorios distintos.

La idea es simple: **todo lo que hago para aprender, va aquí**.

---

## 🎯 Objetivo del repositorio

- Practicar programación en distintos lenguajes
- Consolidar conceptos básicos e intermedios
- Mantener un historial real de aprendizaje y progreso
- Tener ejemplos claros y ordenados para volver a ellos en el futuro
- Que también pueda servir a otras personas que estén empezando

Por eso intento que el código:
- esté **bien comentado**
- sea **legible**
- tenga una **estructura clara**
- priorice el aprendizaje antes que la perfección

---

## 📁 Estructura

El repositorio está organizado principalmente **por lenguaje**.

Dentro de cada lenguaje puedes encontrar:
- ejercicios simples (katas, lógica, práctica de sintaxis)
- ejercicios más complejos
- mini-proyectos de práctica (por ejemplo, un CRUD, aunque no lo considere un proyecto “formal”)

Ejemplo general:

dev-lab/
├── python/

│ ├── estructuras-basicas/
│ └── mini-proyectos/
├── js/

├── documentation/
└── README.md

## 📌 Qué **no** es este repositorio

- No es un proyecto de producción
- No es un framework
- No es un producto terminado
- No todo el código sigue las “mejores prácticas definitivas”

Es un repositorio **vivo**, en constante cambio, igual que el aprendizaje.

---

## 🧠 Para quién puede ser útil

- Para mí, como registro y referencia
- Para personas que estén empezando a programar
- Para quien quiera ver ejemplos sencillos, comentados y progresivos
- Para comparar distintas formas de resolver problemas básicos
