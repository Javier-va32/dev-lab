# 🧩 Ejercicio FizzBuzz

## 🟢 Versión clásica (1–100)

### Nivel: Fácil
Descripción:
Ejercicio básico de bucles e if donde se imprimen:

* "Fizz" si el número es múltiplo de 3
* "Buzz" si es múltiplo de 5
* "FizzBuzz" si es múltiplo de ambos

Conceptos: for, if/elif, operador %

## 🟢 Versión extendida (1–105)

### Nivel: Fácil (elegante)
Descripción:
Similar al clásico, pero concatenando salidas sin else, lo que permite añadir reglas:

* 3 → "Fizz"
* 5 → "Buzz"
* 7 → "Woof"

Si no coincide, se imprime el número.
Usa output or i para mostrar el fallback.

Conceptos: for, acumulación de strings, truthy/falsy, %

🗂 Lenguajes usados

Python

🎯 Notas

FizzBuzz es un ejercicio típico en entrevistas junior para validar que la persona entiende bucles, condicionales y módulo.
